# Backlink plan (2026-11-03)

Why: Search Console (Oct 4 - Nov 1) shows 81 clicks / 7,455 impressions. Pages rank, but the domain has almost no
outside mentions: a web search for "dulceglucosa.com" or the app name returns nothing about Dulce. Google keeps the
English home page `/en` out of the index ("Crawled - currently not indexed", last crawl 2026-08-11) and AI answer
engines cite what other sites say. A few real, relevant links beat any on-page change now.

Claude can't place these: every item needs Giorgi's account, an email from Giorgi, or a community post in his name.
Claude prepares the text; Giorgi sends or posts it.

## Rules

- Google spam policies: no bought links, no link exchanges, no guest posts written for links, no PBNs, no
  "SEO directories". Every link below is one a reader would actually click.
- Communities: say you make Dulce in the first line, answer the question asked, link only when it helps, follow
  each forum's self-promotion rule (most allow it in a relevant thread when disclosed, some only in a weekly thread).
- Never name a country for Dulce or the founder (see no-business-country rule). No Android claims (not released).
- Link to the page in the reader's language, not always the home page. Point English links at `/en` or an English
  guide when it fits: that is the page Google is ignoring.
